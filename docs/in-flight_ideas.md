# In-flight ideas

New ideas under consideration for graptostream. Each entry is a question, not a commitment.

## The dual-platform design

graptostream is the macOS-only companion of indigo-noting, the proposed Rust, Tauri and whisper design for macOS and Linux, written up in the Library at `Proposals/indigo-noting/`. What graptostream teaches (spoken names, the pause that ends an utterance, how apps confirm actions, how apps reply) is to be carried back into that proposal.
